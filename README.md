# Convite Olivia

Site elegante e responsivo para convidar pessoas para o primeiro aniversário de Olivia, com layout moderno, contagem regressiva, mapa e botão para WhatsApp.

## Como executar

```bash
npm install
npm start
```

## Publicação no GitHub Pages

1. Crie um repositório no GitHub.
2. Faça o push do projeto.
3. No GitHub, vá em Settings > Pages.
4. Selecione a branch `main` e a pasta `/docs` ou configure o fluxo de deploy.

## Estrutura

- Angular 20
- Standalone components
- Estilo responsivo e glassmorphism
- Conteúdo preparado para o convite
